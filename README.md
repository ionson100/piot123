 ##### Модуль прокси для проверки кода маркировки
 Что делает это штука:
 Отправляет массив объектов (содержащий код проверки) в модуль ПИоТ\
 получает массив объектов результата проверки.\
 Если еще проще, отсылает код на проверку, получает результат проверки, простой и без излишеств\
 1 Можно ли продавать.\
 2 Код который мы отсылали.\
 3 Цена, которая должна стоять в ценнике на кассе за единицу продукции в рублях (decimal)\
 4 Тег 1265 в чистом виде как строка. \
 Проверка идет через эмулятор https://esm-emu.ao-esp.ru/api/v2/codes/check \
 Проверка ЛМ http://localhost:5995/api/v2/cis/outCheck
##### Единица входных данных
```java
/**
 * Единица входных данных для проверки кода, применима к тестовому сопровождению
 */
public class MInItems {
    /**
     * Полный код, с групповыми разделителями 
     */
    public String km;

    /**
     * Номер проверки кода, по спецификации (https://tspiot.sandbox.crptech.ru/)
     * Эти поля можно не заполнять или вообще исключить в проде
     * или использовать под свои нужды
     */
    public String idCase;

    /**
     * Описание кейса проверки кода по спецификации 
     * Эти поля можно не заполнять или вообще исключить в проде
     * или использовать под свои нужды
     */
    public String descriptionCase;
}
```

##### Результат проверки кода
 ```java
/**
 * Результат проверки кода
 */
public class MOut{

    /**
     * Глобальная ошибка проверки, например 404, 203 тут не живет, таймаут тоже
     * При наличии записи-проверка не прошла
     */
    public String totalErrorMessage;

    /**
     * Список Данных проверки кода (результат проверки), сколько кодов Вы заслали,
     * столько результатов вы получите
     */
    public List<MOutItems>  itemsList;

}
/**
 * Данные проверки единицы кода 
 */
public class MOutItems extends MInItems{

    /**
     * Разрешение продать true-продавать можно, false - продавать нельзя
     */
    public boolean  permitSale;

    /**
     * Причина запрете продажи, это должно отражаться перед мордой кассира
     */
    public String errorMessage;

    /**
     * Строковое значение тега 1265,
     * при аварийной ситуации статус ответа 203, это поле равно null (Продавать можно, не заполняя тег 1260)
     */
    public String tag_1265;

    /**
     * Для группы 3, цена за единицу товара, в рублях, 
     * должна стоять в чеке, независимо что там накрутили бухи в офисе.
     * Внимание! Если код в серой зоне на сервере, или код прошел 
     * проверку в локальном модуле это поле ПУСТОЕ
     */
    public Double mrcTobacco;
}
```
#### Пр тесты
Проверка идет через эмулятор https://esm-emu.ao-esp.ru/api/v2/codes/check \
Проверка ЛМ http://localhost:5995/api/v2/cis/outCheck \
Версия локального модуля 2.0
Для проверки ЛМ, он должен быть запущен и готов к работе\
Внимание: Для проверки нужно указать свои настоящие атрибуты, не мои\
файл UtilsPiot поле ```public static final String AUTHORIZATION ="Basic ваш Base64";```
В точке входа, файл main выбираем кейсы для тестов
```java
  List<MInItems> mInItems = new FactoryTest().initFactory().buildRequest("5.1");
// or   mInItems = new FactoryTest().initFactory().buildRequest("5.1","5.2);
```
Не все кейсы подготовлены на фабрике, например 13 15 16 их нет, по соображением имплементации\
Впрочем при отсутствии кейса выпадет ошибка.\
Внимание: Если Вы будете тестить пакетом, пакет может сломаться, если один из кейсов вернет проверку через ЛМ\
Про кейс с задержкой 5 секунд, там не задержки 5 секунд, \
если ставить таймаут проверки 1500, то все кейсы валятся в локальный модуль, сервер не отрабатывает, \
так что я ставлю 3500, а не кейс с 5 секундами ставлю 1500.\
